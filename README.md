# Digital Café Luna Labs

Digital Café Luna is a hands-on AWS learning project created to move beyond certification theory and into real cloud execution.

The idea behind this project is simple: getting certified in AWS should not stop at answering exam questions. Real cloud learning happens when you design, build, operate, validate, troubleshoot, secure, and clean up cloud environments.

This repository contains practical AWS labs based on a fictional business scenario: a growing digital café that needs to improve its cloud architecture, operational maturity, security posture, automation, and cost visibility over time.

---

## About the project

Digital Café Luna uses a narrative-based learning approach to explain AWS concepts through realistic technical scenarios.

Instead of isolated exercises, each lab represents a small step in the evolution of a cloud environment. The goal is to help learners understand not only how to configure AWS services, but also why a specific architectural or operational decision matters.

The project focuses on practical execution, clear validation, cleanup discipline, and real-world trade-offs.

---

## Why this project exists

Many people prepare for AWS certifications by answering practice questions, memorizing service names, or reviewing isolated concepts.

That helps, but it is not enough.

Cloud professionals also need to understand how services behave in real environments, how decisions affect operations, and how to validate that something actually works.

Digital Café Luna was created to bridge that gap.

---

## Learning approach

Each lab is designed to be:

- Practical and hands-on.
- Based on a realistic business scenario.
- Focused on AWS architecture and operations.
- Clear enough for learners who are still building confidence.
- Validated with concrete checkpoints.
- Finished with cleanup steps to avoid unnecessary costs.
- Connected to AWS Well-Architected principles when relevant.

## How to use these labs

1. Read the scenario and objective of the lab.
2. Review the prerequisites.
3. Follow the step-by-step instructions.
4. Validate the expected result.
5. Review the Well-Architected notes.
6. Clean up all resources created during the lab.

These labs are intended for learning and practice. Always review the AWS resources you create and clean them up when finished.
